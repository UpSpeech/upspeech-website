# Output

Where content generated by the Content System prototype lands.

Three folders, and the order matters.

```text
Output/
├── copy/        the post, the brief, the alt text, the ship checklist
├── templates/   the render targets and the visual system
├── source/      original and edited photographs, with a job log
├── tools/       fal-image.mjs, one fal.ai job at a time, logged
└── exports/     the finished PNGs and PDFs, ready to post
```

**`copy/` is the source of truth for what a post says.** `exports/` is what gets
uploaded. If the two disagree, the copy file is right and the export needs
re-rendering.

## Naming

`<channel>-<nnn>-<slug>` for a copy file. `ig-001-myth-ask-early.md`,
`li-001-visible-week.md`. The number is a running counter per channel, so a post
can be referred to in a conversation without quoting its title.

Export names follow the convention in [`../post-formats.md`](../post-formats.md),
because the renderer picks the output size from the name:

| Name pattern | Output |
| --- | --- |
| `story-*` | 1080 x 1920 |
| `doc-<carousel>-<nn>-<slug>` | 1080 x 1350, assembled into `doc-<carousel>.pdf` |
| everything else | 1080 x 1080 |

## Rendering

```bash
cd templates
npm install          # first time only
npm run export       # renders everything into ../exports/
```

Re-render part of the set by passing names or prefixes:

```bash
npm run export -- doc-visible-week
npm run export -- ig-myth-01-ask-early
```

Needs Google Chrome installed, or `CHROME_PATH` pointing at a Chromium binary.

## The template system

Everything the renderer needs lives in `templates/`, and it reads nothing from
outside `Content System/`.

```text
templates/
├── index.html    the render targets
├── styles.css    the visual system, written from scratch for this folder
├── export.mjs    HTML to PNG, and the pages of a doc-* set into one PDF
├── package.json  sharp and pdf-lib
└── assets/
    ├── fonts/    Outfit, Plus Jakarta Sans, Bricolage Grotesque
    └── brand/    logo.svg, logo-invert.svg
```

No symlinks, no `@import` of anything outside, no shared stylesheet. The fonts
and the logo are copies, so this folder renders correctly on its own.

### The visual system

Built from the principles in [`../brand-signature.md`](../brand-signature.md),
which were read off the reference set in `../Assets/Inspiration from other
companies/`. The devices are ours; none of them reproduce another brand's look.

| Device | Class | What it does |
| --- | --- | --- |
| Aurora ground | `.frame`, `.frame-dark` | Lavender, sky, and mint bleeding in from opposite corners over a near-white or deep-navy field, with a quiet dot grid on top |
| Pill label | `.pill` | The recurring slide tag that makes separate slides read as one series |
| Split headline | `.headline strong` | Bold only on the phrase that carries the idea, regular on the rest, one typeface |
| Gradient numeral | `.numeral` | Numbers as the loudest object on the slide, in the navy to sky to mint gradient |
| Limit tag | `.limit-tag` | What the number does not prove, inside the frame with a gold dot, never in a footnote |
| Travelling ring | `.ring` | A progress ring that fills a little more on each page of a carousel |
| Ghost word | `.ghost` | An oversized word behind the content, cropped by the frame edge |
| Speech bubbles | `.bubbles` | A claim quoted as something somebody said, rather than asserted by us |
| Split square | `.split` | The claim on the dark half, what is actually true on the light half |

## Before anything here is posted

1. The checklist in the copy file is filled in honestly, not assumed.
2. Alt text is in the copy file, and gets pasted when the post goes up.
3. A row goes into [`../content-log.md`](../content-log.md) the same day.
4. Somebody is available to reply for the next 48 hours. See
   [`../community-management.md`](../community-management.md).
